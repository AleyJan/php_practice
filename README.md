# PHP Basics & Practice Lab

An isolated sandbox repository for mastering core PHP development concepts, logic workflows, and syntax execution.

## ⚙️ Environment Setup
* **Local Web Server:** Running WampServer (WAMP) mapped explicitly to the `E:\` partition due to storage limitations (`E:\wamp64\www\php-practice`).
* **Execution Link:** Local code is resolved in the browser via `http://localhost/php-practice/`
* **Development Editor:** VS Code optimized with the **PHP Intelephense** extension.
